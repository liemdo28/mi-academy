## Priority gaps

1. **Sound Match content** — needs audio recordings, no content exists
2. **Math Race question banks** — 50+ addition/subtraction per age group needed
3. **Robot Commands maps** — 20 maps with verified solutions needed
4. **Explorer/Master content** — zero game content for older children yet

## Recommendation

Wave 2 (Word Builder + Sound Match) and Wave 3 (Math) should be prioritized
immediately after Memory Cards ships as the first release.
