# Mi Academy Brand Guidelines

## 1. Brand direction

Mi Academy is a child-friendly educational app for children aged 5-12.

The identity must feel:

- Friendly
- Playful
- Safe
- Educational
- Modern
- AI-assisted, but not robotic or futuristic
- Warm and emotionally expressive

Do not use real children or realistic human photography.

Use a consistent illustrated mascot inspired by expressive sticker characters:
large eyes, rounded face, simple shapes, clean outlines, soft shading,
clear hand gestures, and readable facial expressions.

## 2. Logo

The primary logo consists of:

- The wordmark "Mi"
- A friendly illustrated child mascot interacting with the letter M
- A small star above or near the letter i
- The word "ACADEMY" below the main symbol

The logo must remain recognizable at app-icon size.

Required variants:

- Primary horizontal logo
- Compact stacked logo
- Light-background app icon
- Dark-background app icon
- Monochrome logo
- Symbol-only icon

Do not use a real child's face.
Do not create a photorealistic mascot.

## 3. Mascot

Create one canonical Mi Academy mascot.

Characteristics:

- Cute illustrated child
- Dark brown hair
- Large expressive eyes
- Rounded facial features
- Orange shirt or hoodie
- Friendly, energetic personality
- Sticker-like silhouette
- Soft 2D or subtle 2.5D rendering
- White outline when used as a floating sticker

The mascot must remain visually consistent across all screens.

Create these initial expressions:

1. Welcome / waving
2. Great job / thumbs up
3. Thinking
4. Confused
5. Excited
6. Encouraging
7. Try again
8. Celebration
9. Apology
10. Love / heart
11. Sleeping
12. Surprised

Expressions must be shown visually. Do not depend only on text.

## 4. Color palette

Primary orange:
- Hex: `#FF8A00`
- Usage: primary actions, logo M, highlights

Learning green:
- Hex: `#4CAF50`
- Usage: progress, success, mathematics, positive feedback

Discovery blue:
- Hex: `#4A90E2`
- Usage: navigation, literacy, informational elements

Creative purple:
- Hex: `#8E6BFF`
- Usage: logic, memory, creativity

Achievement yellow:
- Hex: `#FFD23F`
- Usage: stars, rewards, trophies

Deep navy:
- Hex: `#1E2A44`
- Usage: text, headings, dark icon background

Cloud white:
- Hex: `#F4F6FA`
- Usage: app background and surfaces

Colors must meet practical readability requirements.
Do not use yellow for body text on white backgrounds.

## 5. Typography

Primary font:
- Nunito Rounded

Recommended roles:

- Display: Nunito Rounded ExtraBold
- Heading: Nunito Rounded Bold
- Button: Nunito Rounded ExtraBold
- Body: Nunito Sans or Nunito Rounded Medium
- Caption: Nunito Rounded SemiBold

Typography must support Vietnamese and English.

Avoid:

- Thin font weights
- Condensed fonts
- Sharp corporate typography
- Decorative fonts for body text

## 6. UI visual language

Components should use:

- Large rounded corners
- Soft shadows
- Clear visual hierarchy
- Generous touch targets
- High-contrast labels
- Simple iconography
- Limited information per screen
- Friendly micro-animations
- Immediate visual feedback

Preferred corner radius:

- Small control: 12 px
- Standard card: 20 px
- Hero card: 28 px
- Pill: fully rounded

Minimum touch target:
- 48 logical pixels
- Prefer 56-64 logical pixels for primary child-facing actions

Avoid:

- Glassmorphism with poor contrast
- Dense dashboards
- Realistic stock images
- Excessive gradients
- Tiny labels
- Generic Material defaults without customization
- Emoji as permanent production icons

## 7. Icon style

Icons must be:

- Rounded
- Friendly
- Colorful
- Simple
- Recognizable without text
- Consistent in stroke and volume

Core icon families:

- Alphabet
- Numbers
- Logic
- Memory
- Writing
- Listening
- Rewards
- Profile
- Settings
- Parent area

Use SVG or Flutter vector-compatible assets where possible.

## 8. AI design direction

"AI-inspired" means:

- Adaptive guidance
- Smart recommendations
- Context-aware mascot reactions
- Personalized progress
- Gentle animated feedback
- Dynamic learning paths

It does not mean:

- Robots everywhere
- Neon cyberpunk effects
- Dark futuristic interfaces
- Technical AI terminology shown to children

The AI should feel like a friendly learning companion.

## 9. Accessibility and child safety

- Do not depend on color alone.
- Use icon + color + label where appropriate.
- Support larger text without broken layouts.
- Maintain readable contrast.
- Avoid flashing animations.
- Provide reduced-motion behavior.
- Parent-facing actions must be visually separated.
- Avoid manipulative reward mechanics.
- No external ads or unsafe external links in child-facing screens.

## 10. Localization

All interfaces must support:

- Vietnamese
- English

Do not hardcode user-facing strings.

Account for longer Vietnamese labels and diacritics.
Test every primary screen in both languages.
