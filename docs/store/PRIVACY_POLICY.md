# Mi Academy Privacy Policy Draft

Last updated: 2026-07-23

Mi Academy is a child-friendly educational app designed for children ages 5-12 and their families.

## Summary

Mi Academy is offline-first. Child-facing gameplay can work without sending data to a server. If parent-enabled sync is configured, Mi Academy may store learning progress so parents can view progress across sessions.

## Information We Collect

Mi Academy may collect:

- Child nickname.
- Avatar selection.
- Age group.
- Language preference.
- Game progress.
- Daily session time.
- Stars and badges.

Mi Academy does not collect:

- Child real name.
- Email address from children.
- Phone number.
- Precise location.
- Contacts.
- Advertising ID.
- Camera data.
- Social media accounts.

## How We Use Information

We use information to:

- Show the child profile.
- Save learning progress.
- Recommend suitable learning activities.
- Show parent-facing progress summaries.
- Support Vietnamese and English localization.

## Sharing

Mi Academy does not sell child data and does not share child data for advertising.

## Parent Controls

Parents can:

- View progress in the parent area.
- Export available data.
- Delete child profile data.
- Keep the app offline-first by not enabling sync.

## Security

Mi Academy is designed to keep child-facing flows simple and offline-first. Any server sync should use authenticated API access and environment-specific secrets managed outside the mobile app.
